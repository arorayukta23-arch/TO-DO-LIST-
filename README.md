# Yukta Arora — Personal Portfolio Website

A fully responsive, accessible, multi-page personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

## 🌐 Live Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — Hero section with intro, CTAs, and social links |
| `about.html` | About — Education, skills, and background |
| `projects.html` | Projects — AI project showcase cards |
| `resume.html` | Resume — Timeline, skills, achievements, and download |
| `contact.html` | Contact — Accessible form with validation and info cards |

## ✅ Features

### Accessibility (WCAG 2.1)
- Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- ARIA attributes (`aria-label`, `aria-labelledby`, `aria-describedby`, `role`, `aria-expanded`)
- Skip-to-content link
- Visible focus indicators
- Keyboard-accessible navigation
- Reduced motion support (`prefers-reduced-motion`)
- High contrast mode support (`forced-colors`)
- Screen reader announcements for form validation
- Minimum 44×44px touch targets

### SEO
- Unique `<title>` per page
- Meta description, keywords, author, canonical URL
- Open Graph and Twitter Card tags
- Favicon
- Proper heading hierarchy (single `<h1>` per page)
- Semantic HTML structure

### Design
- Modern minimal UI with professional color palette
- Sticky glass-morphism navigation
- Card-based layouts with soft shadows
- Smooth hover animations and scroll-triggered fade-ins
- Responsive across Desktop, Laptop, Tablet, and Mobile
- CSS Flexbox and Grid layouts
- Google Fonts (Inter)

### JavaScript Features
- Mobile hamburger menu with overlay
- Smooth scrolling for anchor links
- Scroll-to-top button
- Active navbar highlighting
- Intersection Observer scroll animations
- Accessible form validation with real-time feedback

## 🚀 How to Run

1. Open the `Portfolio` folder
2. Open `index.html` in any modern browser
3. Navigate between pages using the top navigation

No build tools or dependencies required — pure HTML, CSS, and JavaScript.
